Pale Apollo

Official website for Pale Apollo — a custom-built music player and band hub. 
Live at paleapolloband.com.

---Features---

 Custom HTML/CSS/JS audio player with playback controls
 Direct links to Instagram and email contact
 Fully responsive design

 ---Tech Stack---

HTML
CSS
JavaScript

No frameworks or no dependencies

---Getting Started---

Clone the repo

git clone https://github.com/ZachDAmico/pale-apollo.git

Open the project in VS Code

cd pale-apollo
code .

Run with Live Server

Install the Live Server extension in VS Code if you haven't already
Right-click index.html and select "Open with Live Server"
The site will open in your browser at http://127.0.0.1:5500

Alternatively, you can open index.html directly in your browser — no server needed.
